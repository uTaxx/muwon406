# 뉴캐슬 파일럿 7차 — 예측 모델 고도화 (2026-10-20)

사건 기사 표시는 방향 추정이 유효한지 검증한 뒤에 반영하기로 해서(`hub.html`은 `?coalev=1`일 때만 표시), 예측 모델 쪽을 먼저 보강했다.

## 1. 요약

| 질문 | 결과 |
|---|---|
| 지금까지 방향 예측이 안 된 이유 | 비교 기준과 정보 시점이 약했다. 이번 달 말일의 현물 가격을 쓰지 않았다. |
| 말일 현물을 쓰면 | 다음 달 월평균 예측의 표본 밖 R²가 0.07 이하에서 0.27~0.42로, 방향 적중이 약 55%에서 61~71%로 올랐다. |
| 그것이 새로운 예측력인가 | 아니다. 같은 값은 「다음 달 평균 = 지금 현물」이라고 두기만 해도 나온다(R² 0.42, 방향 71%). 월평균은 지연되어 따라오므로 현물이 월평균보다 앞서 있는 정보를 쓴 것이다. |
| 현물 기준으로 더 맞히는 변수가 있는가 | 없다. 가스·유가·환율·주가·구리·모멘텀을 모두 넣어도 현물 대비 추가 변화의 R²는 -0.10~0.01이다. 방향 적중 51~61%이고 p<0.05인 2개 설정도 R²가 0 이하라 쓸 수 없다. |
| 범위 예측은 | 현물 중심 + 변동성 폭이 가장 좋다. 1개월 구간 적중 80.9%(목표 80%), 핀볼 손실이 이전 방식(이번 달 평균 중심)보다 24% 낮다. |
| 운영에 쓰려면 | 최신 현물 지수가 필요하다. IMF 월별은 약 3개월 지연이고, 야후의 뉴캐슬 선물(MTF=F)은 2025-12에서 멈췄다. ICI4·ICI5 주간 데이터가 이 역할을 한다. |

## 2. 방향 예측이 달라진 이유
- 3~6차의 예측 대상은 「다음 달 월평균 / 이번 달 월평균」이었다. 월평균은 월 중간에 가격이 바뀌면 다음 달에도 따라 움직이는 것처럼 보이는 지연 효과가 있다(월 수익률 자기상관 0.26).
- 이번에는 이번 달 말일의 현물 가격과 이번 달 평균의 괴리(`말일 / 월평균`)를 입력에 넣었다. 선물 일 종가는 이 데이터에서 말일 값을 준다.
- 결과(IMF 월평균을 목표로, 2014-01~2025-12, 144개월):

| 입력 | R² | 방향 적중 | p |
|---|---|---|---|
| 말일 현물 괴리만 | 0.24~0.27 | 61% | 0.005 |
| +5일 변화·모멘텀 | 0.19~0.27 | 60~63% | 0.01~0.05 |
| +가스·유가·환율 | 0.23~0.24 | 61~65% | <0.01 |
| +주가·구리 | 0.31~0.34 | 64~65% | 0.001 |

- 뉴캐슬 선물 월평균을 목표로 하면 R² 0.36~0.41, 방향 적중 70~76%다(143개월).
- 한계: 이 개선은 월평균이 지연 지표라서 생기는 것이다. 현물 가격이 오를지는 예측하지 않는다.

## 3. 현물 기준으로 추가 예측력이 있는가
- 비교 기준: 다음 달 평균 = 이번 달 말일 현물. 이 기준만으로 R² 0.42, 방향 71%다.
- 새로 맞힐 대상: 다음 달 평균이 말일 현물에서 얼마나 더 벗어나는가(`다음 달 평균 / 말일 현물`).

| 입력 | R² | 방향 적중(p) |
|---|---|---|
| 말일 괴리·5일·모멘텀 | -0.10~-0.04 | 54~57% (0.06~0.21) |
| 가스·유가·환율 | -0.04~0.00 | 59~61% (0.007~0.03) |
| TTF 포함(2020-10~) | -0.01~0.01 | 52~55% (0.34~0.54) |
| 주가·구리 | -0.02~0.00 | 59~61% (0.009~0.03) |

- 현물을 기준으로 두면 추가로 얻는 정보가 없다. 설정이 8개라 p값이 0.03 이하인 것이 우연으로 나올 수 있고, R²가 0 이하라 예측 값이 실제 크기를 못 맞힌다.
- 선물 시장 가격에 이미 모든 변수가 반영되어 있고, 월평균 하나를 맞히려면 현물 정보 이상의 것을 찾아야 한다는 뜻이다.

## 4. 범위(예측 구간) 모델
중심을 말일 현물로 두고, 폭은 최근 변동성(EWMA, 감쇠 0.9)에 과거 표준화 변화의 경험 분위수(10·50·90%)를 곱한다. 예측 시점에 확정된 과거만 쓰는 워크포워드이고 평가는 2015-01부터다(선물 월평균, 약 130개월).

| 기간 | 모델 | 80% 구간 적중 | 핀볼 손실 |
|---|---|---|---|
| 1개월 | **현물 중심 + 변동성 폭** | **80.9%** | **0.062** |
| 1개월 | 이번 달 평균 중심 + 변동성 폭(이전 방식) | 71.0% | 0.082 |
| 1개월 | 현물 중심 + 고정 폭 | 63.4% | 0.065 |
| 2개월 | 현물 중심 + 변동성 폭 | 80.8% | 0.127 |
| 2개월 | 이번 달 평균 중심 + 변동성 폭 | 77.7% | 0.134 |
| 3개월 | 현물 중심 + 변동성 폭 | 77.5% | 0.174 |
| 3개월 | 이번 달 평균 중심 + 변동성 폭 | 79.1% | 0.179 |

- 1개월에서 이전 방식 대비 구간 적중이 목표에 맞고 손실이 24% 줄었다. 2~3개월은 개선 폭이 5%와 2%로 작다.
- 가스(TTF) 변동성으로 폭을 추가 보정하는 방법도 시험했다. 핀볼 손실이 오히려 높아져(1개월 0.085 → 0.087~0.102) 채택하지 않았다.
- 월평균만 알 때(IMF 월별, 중심은 마지막 월평균)의 구간 적중은 1·2·3개월 77.5·75.9·75.7%로 목표보다 조금 낮다.

## 5. 산출물
- `예측모델_v1.py`: 현물 모드(주·일 지수)와 월평균 모드를 지원하는 범위 예측 모델. 백테스트와 최신 예측을 JSON으로 낸다. 방향은 예측하지 않는다.
  - 월평균 모드 시험 결과: 마지막 데이터 2026-07(140.4 $/t) 기준 2026-08 하단 129.8·중심 140.3·상단 152.3, 2026-09 122.4·139.5·159.6, 2026-10 117.8·138.3·169.7($/t, 10~90% 범위). 이 값은 IMF가 약 3개월 지연이라 2026-10의 실제 현물 수준을 반영하지 못한다.
- `예측검증_*.py`와 결과 json: 위 표의 재현 스크립트(가격 원데이터는 `fetch_yahoo.py`로 받는다).

## 6. 다음 단계
1. **최신 현물 지수 확보(필수).** 운영 예측의 정확도는 현물이 얼마나 최신인가에 달려 있다. ICI4·ICI5 주간 데이터를 `시장지표값` 시트로 받을 수 있는지(계열사 구독 범위, 수집 방법) 확인한다. 받으면 현물 모드로 같은 백테스트를 ICI에 반복한다.
2. **데이터가 없는 동안의 임시안.** 월평균 모드로 IMF 월별에서 범위만 낸다. 지연이 3개월이므로 「3개월 전 기준」을 화면에 함께 표시해야 한다.
3. **대시보드 반영.** 사건 기사 방향 검증과 이 범위 모델을 함께 보고 반영 여부를 정한다. 범위 모델을 n8n으로 옮기는 것은 현물 데이터가 정해진 뒤에 한다(Code 노드 이식은 `예측모델_v1.py`가 그대로 대응한다).
4. **방향 예측.** 현물 기준으로 추가 예측력이 없다는 결과가 나왔으므로, 방향 예측은 정책·수급 정량 변수(중국 재고·수입량·운임)를 확보한 뒤에만 다시 시험한다.
