LX Group MI 시스템 설명 (2026-11-06 기준)
=========================================

이 파일은 다른 세션에 이 시스템을 설명하기 위한 요약이다.
자세한 현재 상태와 변경 이력은 docs/HANDOVER.md, 작업 규칙은 CLAUDE.md를 본다.


1. 무엇인가
-----------
LX그룹 지주사용 시장 정보(MI, Market Intelligence) 대시보드다.
계열사(LX인터내셔널, 판토스, 하우시스, 글라스, 세미콘, MMA, 홀딩스)별로 아래 데이터를 모아 웹 화면 하나에서 보여 준다.
- 뉴스: 키워드별 기사 수집, AI 점수(중요도·관련성·긴급성), 메일 발송
- 경쟁사 실적: DART 정기보고서 원문에서 부문별 매출·영업이익·비용 추출
- 시장 지표: 환율·금리·원자재·운임(ECOS, FRED, 관세청, KOSIS, KCCI)
- 공시: 계열사·경쟁사 공시, 시장 전체 딜 공시(지분 거래, 합병·분할 등)
- 주요 일정, 관심 기업, 실리코시스 소송 사건 추적
- 석탄 가격 파일럿(뉴캐슬 석탄 예측 범위 모델, 사건 기사 수집) — 검증 중


2. 구성
-------

  - 대시보드: public/lxgroup-mi/hub.html

[백엔드] n8n Cloud (sondullab.app.n8n.cloud)
  - LXGroup_ 로 시작하는 워크플로우 43개. 같은 인스턴스에 개인용(AutoTrading_, SondulNews_ 등)이 섞여 있으니 건드리지 않는다.

    b) 조회 웹훅: 대시보드가 호출하고, 시트를 읽어 반환만 한다
    c) 관리 웹훅: 대시보드 설정 화면에서 시트 행을 추가·수정·삭제한다
  - 실패하면 LXGroup_실패알림(HlJf0FoPoSjQiaTL)이 텔레그램으로 알린다(각 워크플로우의 오류 워크플로우로 지정).

[저장소] Google Sheets / Drive (공용 Google 크리덴셜)
  - 설정 스프레드시트: 설정, 운영설정(API 키), 시장지표값, 경쟁사, 경쟁사공시, 경쟁사실적, 경쟁사비용, 딜공시, 회사공시 등의 탭
  - 고객별 기사 시트, 석탄 사건 수집 시트
  - 드라이브: 경쟁사별 DART 원문 폴더, 실적·지표 마스터 스프레드시트, 대시보드용 공개 JSON 3개(기사, 상장·비상장 기업 목록)

[AI] Claude API — 뉴스 점수 매기기(LXGroup_MI_Sub). 키는 「운영설정」 시트에 있다.
  비용 문제로 새 AI 분류 기능은 API를 쓰지 않고 규칙 기반으로 만든다.

5. 반드시 지킬 것
-----------------
- 저장소가 공개다. API 키·비밀번호·토큰을 어떤 파일에도 넣지 않고, 대화에도 출력하지 않는다.
- 운영설정 시트를 입력으로 받는 Code 노드에서 throw 하지 않는다(에러에 키가 첨부됨). 진단용 아이템을 return 한다.
- LXGroup_지표수집, LXGroup_경쟁사_공시수집은 saveDataSuccessExecution: none 유지.
- 라이브 워크플로우는 draft를 수동 실행해 확인한 뒤 publish 한다.
  addNode는 executeOnce/alwaysOutputData를 무시하므로 setNodeSettings로 따로 지정한다.
- 시트·노드·컬럼 이름, 웹훅 파라미터(예: 갈래)는 바꾸지 않는다. 워크플로우와 어긋난다.
- 삭제는 휴지통으로만 한다.
- 글은 일반적인 한국어 실무 문체로 쓴다(CLAUDE.md 금지어 표 참고).
