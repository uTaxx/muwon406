# ADR-005 — AI 비용 통제 정책

- **상태**: Accepted
- **날짜**: 2026-08-05

## 맥락

Claude API는 사용량에 따라 과금되며, Pilot 예산은 월 목표 $15 / 절대 상한 $20으로 엄격히
제한된다. 통제 없이 모든 기사를 Claude에 전달하면 예산을 빠르게 초과할 수 있다.

## 결정

1. **AI 미사용 우선**: 날짜 필터, URL 중복제거, 제목 유사도, 출처 등급, 키워드 매칭, 금액/날짜
   정규화, 링크 상태 확인은 전부 규칙 기반(n8n Code 노드/Python)으로 처리하고 AI를 호출하지
   않는다.
2. **애매한 건만 1차 분류 AI 호출** (WF-P04), **신규 중요 사건만 심층분석 AI 호출** (WF-P05).
3. **토큰 상한**: 입력 최대 8,000 / 출력 최대 1,200 tokens per call.
4. **일일 심층분석 상한**: 5건.
5. **단계별 자동 통제**: 월 예산 70% 도달 시 경고, 90% 도달 시 심층분석은 긴급 건만, 100% 도달
   시 Claude API 자동 중지.
6. 모든 호출의 `usage.input_tokens`/`usage.output_tokens`를 COST_LOG에 기록하고
   `scripts/cost_guard.py`가 누적 비용을 계산한다.
7. 모델명은 코드에 하드코딩하지 않고 `config/cost_policy.yaml` 또는 CONFIG_MASTER에서 관리한다.

## 이유

- 규칙 기반 전처리만으로도 관련 없는 기사 대부분을 걸러낼 수 있어 AI 호출 자체를 줄일 수 있다.
- 단계별 통제(70/90/100%)로 예산 초과를 사전에 방지하면서도 완전 중단 이전에 "긴급 건만 허용"
  단계를 두어 중요 리스크를 놓치지 않는다.

## 트레이드오프

- 규칙 기반 필터가 너무 엄격하면 관련 기사를 놓칠 위험(false negative) → 운영 중 정기적으로
  키워드·임계값을 점검 (`DEVELOPMENT_MANUAL_REFERENCE.md` §11 매주 점검 항목)
- 토큰 상한이 낮으면 복잡한 사건의 심층분석 품질이 제한될 수 있음 → Pilot 단계에서는 비용
  통제를 우선하고, 필요 시 향후 CONFIG_MASTER를 통해 상한 조정
