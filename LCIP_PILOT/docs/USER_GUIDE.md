# LCIP Pilot 사용자 설명서 — 전략팀용

Architect Review Round 11 Priority 5("사용자 설명서를 개발자 관점이 아니라 전략팀
직원 관점으로 다시 작성한다. 5분 안에 사용할 수 있어야 한다")에 따라 작성했다.
`README.md`는 개발자용(설치·테스트) 문서이고, 이 문서는 **실제로 회사를 조사하고
결과를 보는 방법만** 다룬다.

---

## 이 Pilot이 하는 일 (한 문장)

회사 이름 하나를 입력하면, 그 회사의 개요·경쟁사·재무 스냅샷·LX와의 관련성·투자
시그널을 한 번에 정리해서 보여준다. 지금은 **엔지니어드스톤·실리코시스 리스크
모니터링** 하나의 주제로 동작한다.

**꼭 알아야 할 것**: 이 Pilot은 아직 실제 AI/외부 API에 연결되지 않은 시범판
(RC1)이다. 일부 결과는 "Mock"(예시)이며, 화면과 보고서 어디에나 "confidence:
low" 또는 "mock"이라는 표시가 있으면 그 부분은 아직 초안 수준이라는 뜻이다.

---

## 시작하기 전 딱 한 번만 (최초 1회, 약 2분)

터미널(명령 프롬프트)을 열고 아래를 순서대로 입력한다. 이미 해봤다면 건너뛴다.

```bash
cd LCIP_PILOT
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

이후로는 이 화면(터미널)에서 회사 이름만 바꿔가며 실행하면 된다.

---

## 5분 안에 해보는 3가지

### 1) 회사 하나 조사하기 (가장 많이 쓸 기능)

```bash
python3 scripts/scenarios/scenario_3_investment_review.py "회사명"
```

- `"회사명"` 자리에 조사하고 싶은 회사 이름을 넣는다. 예: `"LX Hausys"`, `"KCC"`,
  `"Caesarstone"`.
- 실행이 끝나면 화면 맨 아래 **"결과 요약"**에 다음이 바로 보인다: 회사명,
  종합 점수(Company Intelligence Score), 투자 추천 신호, 추천 사유, 보고서
  파일 3개의 위치.
- 회사 이름을 안 넣고 그냥 실행하면 기본값으로 LX Hausys를 조사한다.

**지금 바로 신뢰할 수 있는 회사(TOP10, 실제 리서치 완료)**: LX Hausys, KCC,
한샘(Hanssem), Caesarstone, Cosentino, Shaw Industries, LIXIL, YKK AP, Schüco,
Saint-Gobain. 이 외 회사는 아직 "미확인" Mock 결과만 나온다.

### 2) 결과 보기 — 3가지 파일 중 무엇을 볼지

1번을 실행하면 `output/quick_company_scan_exports/` 폴더에 파일 3개가 생긴다.

| 파일 | 용도 | 언제 보나 |
|---|---|---|
| `{회사명}_executive_report.html` | **임원 보고용 1페이지 요약** | 상사에게 바로 보여줄 때 |
| `{회사명}.md` | 상세 보고서(회사개요·경쟁사·재무·Peer 비교표 전체) | 직접 검토·근거 확인할 때 |
| `{회사명}.json` | 기계 판독용 원본 데이터 | 다른 시스템에 넘길 때(평소엔 안 봐도 됨) |

`.html` 파일은 더블클릭하면 바로 브라우저에서 열린다. 인쇄하거나 PDF로 저장하려면
브라우저의 "인쇄 → PDF로 저장"을 쓰면 된다.

### 3) 오늘 상황 한눈에 보기 — Dashboard

```bash
python3 scripts/scenarios/scenario_1_news_analysis.py
```

이 명령을 실행하면 `output/pilot_data/dashboard.html`이 생성/갱신된다. 더블클릭해서
열면 첫 화면(Home)에 다음 5가지가 바로 보인다.

1. 오늘의 핵심 Intelligence
2. Quick Company Scan 실행 방법(위 1번 명령)
3. Investment Review 실행 방법(1번 명령에 이미 포함되어 있음 — 따로 실행할 필요 없음)
4. 최근 분석 결과(방금 조사한 회사들)
5. 최근 뉴스

회사를 조사하거나 뉴스 분석을 실행할수록 이 화면의 "최근 분석 결과"/"최근 뉴스"가
계속 갱신된다 — 최신 10건만 보여주므로 오래된 내용에 파묻히지 않는다.

## 자주 묻는 질문

**Q. 결과가 이상하거나 "mock"이라고만 나와요.**
등록되지 않은 회사이거나(TOP10 외), 아직 실제 API에 연결되지 않은 항목(재무
배수, 정책/뉴스 분석 등)이다. 오류가 아니라 Pilot의 현재 단계(RC1)에서 정직하게
표시하는 것이다.

**Q. 이 결과를 그대로 투자 결정에 써도 되나요?**
아니오. "추가 검토가 필요한지" 판단하는 스크리닝 신호까지만 제공한다. 최종
투자판단 자료로는 쓰지 않는다.

**Q. 회사 이름을 어떻게 써야 인식되나요?**
정식 회사명, 흔히 쓰는 약칭, 티커, DART 등록명 중 아무거나 써도 된다(예:
"LX하우시스", "LX Hausys", "108670" 전부 인식). 인식이 안 되면 결과에 "미등록"
으로 정직하게 표시된다 — 임의로 정보를 지어내지 않는다.

**Q. 매번 명령어를 쳐야 하나요? 클릭으로 안 되나요?**
현재 Pilot은 별도 서버 없이 정적 화면 + 명령어로 동작하는 구조라 그렇다. 명령어
한 줄(회사명만 바꾸는 것)이 전부이고, 실행 후 결과 요약이 화면에 바로 뜨므로
파일을 따로 열어볼 필요는 없다.

**Q. 문제가 생기면 누구에게 물어보나요?**
`CLAUDE.md`와 `docs/03_BUILD_SPECIFICATION.md`가 이 Pilot의 설계 원칙과 제약을
담고 있다 — 개발 관련 문의는 이 문서들을 기준으로 한다. 시연 관련 질문/답변
예시는 `docs/PILOT_DEMO_PACKAGE.md`를 참고한다.

## 하지 않는 것 (정직하게 밝힘)

- 30개 등록 회사 중 TOP10만 실제 데이터가 있다. 나머지는 아직 Mock이다.
- DCF 등 정밀 가치평가는 제공하지 않는다(Comparable 비교까지만).
- PDF 파일을 직접 생성하지 않는다(HTML을 브라우저에서 인쇄하면 된다).
- 내부 비공개 정보는 다루지 않는다 — 전부 공개정보 기반이다.
