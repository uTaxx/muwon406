# server — 회사 서버용 프로그램 (계획)

기존에 n8n·구글 시트·드라이브·GitHub Pages로 돌던 LX Group MI 시스템을 회사 서버 한 대에서 도는 프로그램으로 옮기기 위한 폴더다. 아직 코드는 없다.

## 목표 구조

| 현재 | 이 프로그램 |
|---|---|
| n8n 워크플로우 43개 | 프로그램 모듈과 스케줄러 |
| 구글 시트 | 데이터베이스(SQLite로 시작) |
| 드라이브 파일 | 서버 폴더. DART 원문은 복사하지 않고 다시 받는다 |
| GitHub Pages 대시보드 | 프로그램이 `hub.html`을 직접 제공(사내망 전용) |
| Gmail·텔레그램 | 회사 SMTP 메일, 필요하면 팀즈 웹훅 |
| 운영설정 시트의 API 키 | 서버의 `.env` 파일(저장소에 커밋하지 않는다) |

언어는 Node.js(타입스크립트)를 권장한다. n8n 코드 노드가 자바스크립트라서 검증된 로직을 거의 그대로 옮길 수 있다.

## 1단계 — 뉴스 MI

기존 `LXGroup_MI`·`LXGroup_MI_Sub`와 같은 결과를 내는 것이 기준이다.

1. 설정 파일로 분리: 키워드 그룹, 분석 목적, 점수 기준, 최소 점수, 수신자, 참고자료, 피드백 예시
2. 수집: 구글 뉴스 RSS(그룹별 키워드), 필요하면 네이버. 기존 기사와 제목·링크로 중복 제거
3. 점수 매기기: 관련성·중요도·긴급성, 방향, 같은 사건 묶음, 사유. 링크와 제목 앞머리로 결과를 검산한다(2026-09-01 번호 밀림 사고 방지)
4. 발송: 메일 조립과 SMTP 발송. 실행 시각은 평일 07·11·16시
5. 기록: 발송한 기사 목록을 데이터베이스에 저장
6. 병행 운영: 3~5일간 기존 n8n 결과와 기사 목록·점수를 비교한 뒤 전환

운영 중인 고객은 LX홀딩스 1건이다. 다중 고객 처리는 필요 없다.

## 2단계 — 지표·공시·경쟁사 실적

지표 수집(ECOS·FRED·관세청·KOSIS·KCCI), 딜공시, 회사공시, DART 원문 저장·실적 추출·비용 추출, 마스터 엑셀 생성.

## 3단계 — 화면과 데이터 이전

`public/lxgroup-mi/hub.html`의 n8n 웹훅 주소 29곳을 프로그램 API로 교체하고, 구글 시트의 수작업 입력 데이터(키워드, 설정, 피드백, 경쟁사 목록)를 데이터베이스로 가져온다.

## 시작 전에 정해야 할 것

1. 서버 운영체제와 상시 가동 여부
2. 사내 SMTP 메일 발송 가능 여부와 계정
3. 외부 접속 허용 여부(DART, ECOS, FRED, KOSIS, 관세청, 구글 뉴스, 네이버, Anthropic API)
4. 유지보수 담당자
5. 점수 매기기 방식: 회사 Claude API 키, 규칙 기반, 점수 없음 중 선택
